Put your source PNGs here to be auto-recolored.

- stickers/: 512×512 PNGs recommended; any PNG will be resized to 512×512.
- emojis/: 100×100 PNGs recommended; any PNG will be resized to 100×100.

Filenames can be anything. Transparency is preserved. The bot tints color regions to the requested hex while keeping shading.
